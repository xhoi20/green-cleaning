
# Green Cleaning - Laundry Management System

Web application for managing laundry and dry cleaning business operations. Built to help small laundry businesses track customers, orders, services, and generate reports.

## Features

- Customer management and order tracking
- Service catalog with pricing
- Order status workflow (received → washing → ready → delivered)
- Invoice generation
- Daily and monthly reports
- Search and filter orders
- User-friendly web interface
 JWT authentication and authorization
- Role-based access control (Admin, Customer)
 - Secure password hashing
## Tech Stack

- **Backend:** Java, Spring Boot
- **Frontend:** Thymeleaf, HTML, CSS, JavaScript
- **Database:** SQL Server
- **ORM:** Hibernate / JPA
- **Build Tool:** Maven
